**Highlights**

- **Self-documenting API** with DRF Spectacular — OpenAPI schema and browsable docs generated from the serializers
- **Commission report** aggregated per salesperson over an arbitrary date range, with the period total
- **Expandable sale rows** showing line items, unit price, commission rate and commission amount per product
- **Reproducible tooling**: uv, pnpm, Docker Compose, lefthook git hooks and GitHub Actions, all wrapped behind a Makefile

**Overview**  
Educational app covering weight training, nutrition, supplementation, lab exams and health: a curated library, search across every content type, learning tracks, and an AI assistant that answers **only from the approved knowledge base**. It explicitly does not replace professional assessment.

**Highlights**
- **AI assistant with guardrails**: every answer carries an **evidence-strength badge**, a **safety alert** when a condition demands medical advice, and the **sources** it was drawn from — no free-form generation outside the approved library
- **Clean Architecture + DDD**, feature-first: `domain` (entities, value objects, repositories, use cases) → `data` (models, fixture-first datasources) → `presentation` (BLoC/Cubit, pages, widgets), with features isolated from each other
- **Design system in Atomic Design** — contrast-validated tokens, atoms, molecules, organisms, templates and a `/dev/gallery` route, covered by **golden tests** in light and dark
- **Consent and onboarding flow** built into the domain: mandatory terms, health-data authorization, then a goal/experience questionnaire that personalizes the tracks
- **Enforced coverage gates**: 90% domain, 80% data, 80% bloc, checked by a dedicated script alongside `flutter analyze` at zero issues (very_good_analysis)
- **Mock-first**: fixture-backed datasources let the whole product run and be tested without a backend
